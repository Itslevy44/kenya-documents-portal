# InfinityFree Hosting Setup Guide

Step-by-step guide for deploying Kenya Docs on [InfinityFree](https://infinityfree.net) shared hosting.

## 1. Create Your InfinityFree Account & Domain

1. Sign up at [infinityfree.net](https://infinityfree.net).
2. Create a new hosting account and choose a subdomain (e.g., `kenyad.infinityfreeapp.com`) or add a custom domain.
3. Note your **FTP hostname**, **FTP username**, **FTP password**, and **MySQL host/DB/user/password** from the control panel.

## 2. Select PHP Version

1. In the InfinityFree control panel, go to **Software → Select PHP Version**.
2. Choose **PHP 8.2**.
3. Enable the following extensions: `mbstring`, `pdo_mysql`, `zip`, `gd`, `fileinfo`.

## 3. Create MySQL Database

1. In the control panel, go to **Databases → MySQL Databases**.
2. Create a new database and user — note the credentials.
3. Update your GitHub secret `DB_*` variables or set them directly in `.env` if deploying manually.

## 4. Configure GitHub Actions Secrets

In your GitHub repository → **Settings → Secrets and variables → Actions**, add:

| Secret Name           | Value                                             |
|-----------------------|---------------------------------------------------|
| `FTP_SERVER`          | FTP hostname from InfinityFree cPanel             |
| `FTP_USERNAME`        | FTP username                                      |
| `FTP_PASSWORD`        | FTP password                                      |

## 5. Configure Application Environment

After deploy, create/edit `.env` in `htdocs/` via FTP or the File Manager:

```env
APP_NAME="Kenya Docs"
APP_ENV=production
APP_KEY=base64:YOUR_KEY_HERE
APP_DEBUG=false
APP_URL=https://yourdomain.infinityfreeapp.com

DB_CONNECTION=mysql
DB_HOST=sql-host.provided.by.infinityfree
DB_PORT=3306
DB_DATABASE=your_db_name
DB_USERNAME=your_db_user
DB_PASSWORD=your_db_password

CACHE_DRIVER=file
SESSION_DRIVER=file
QUEUE_CONNECTION=sync

AT_USERNAME=...
AT_API_KEY=...
PAYHERO_API_KEY=...
PAYHERO_CHANNEL_ID=...
PAYHERO_WEBHOOK_SECRET=...
TELEGRAM_BOT_TOKEN=...
TELEGRAM_CHANNEL_ID=...
```

Generate `APP_KEY` locally with `php artisan key:generate --show` and paste the output.

## 6. Run Migrations

InfinityFree has no SSH access. Options:

**Option A — Web artisan (temporary route, remove after use)**

Add a temporary route in `routes/web.php`:
```php
Route::get('/setup-db', function() {
    Artisan::call('migrate', ['--force' => true]);
    return 'Done: ' . Artisan::output();
})->middleware('...'); // protect with a secret token
```

**Option B — PhpMyAdmin**

Import the SQL generated by `php artisan migrate --pretend` locally, or run `php artisan migrate` on a local copy with the same DB structure then export and import.

## 7. .htaccess Notes

The `public/.htaccess` in this project handles:
- `RewriteEngine On` — routes all requests through `index.php`
- Automatic HTTPS redirect
- 1-year cache headers for static assets
- Disabled directory listing

InfinityFree supports `mod_rewrite`. No extra configuration is needed.

If PHP requests fail, uncomment the PHP handler line in `public/.htaccess`:
```
AddHandler application/x-httpd-php82 .php
```

## 8. Storage Permissions

InfinityFree uses a standard cPanel file manager. The `storage/` and `bootstrap/cache/` directories need write permission (755 or 775):

1. Open File Manager → navigate to `htdocs/storage/` and `htdocs/bootstrap/cache/`.
2. Right-click → **Permissions** → set to **755**.

## 9. Verify Deployment

1. Visit `https://yourdomain.infinityfreeapp.com` — you should see the Kenya Docs home page.
2. Check `https://yourdomain.infinityfreeapp.com/up` — Laravel health endpoint should return `{"status":"up"}`.
3. Check browser DevTools → Application → Service Workers — confirm `sw.js` is registered.

## Troubleshooting

| Problem | Solution |
|---------|----------|
| 500 error after deploy | Check `storage/logs/laravel.log` via FTP; usually a missing `.env` key or write-permission issue |
| Blank page | Enable `APP_DEBUG=true` temporarily to see the error |
| OTP SMS not sending | Verify `AT_USERNAME` and `AT_API_KEY`; check Africa's Talking dashboard logs |
| M-Pesa payment not confirming | Verify `PAYHERO_WEBHOOK_SECRET` and that the webhook URL is not behind CSRF (`/api/webhooks/payhero`) |
| CSS not loading | Confirm `APP_URL` is the correct full HTTPS URL; check `.htaccess` is uploaded |
