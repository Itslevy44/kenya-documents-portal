# Kenya Document Assistant

A Laravel 11 web application that lets Kenyan citizens generate official document templates (affidavits, letters, forms) in PDF and DOCX format for KSh 50 per document, paid via M-Pesa (PayHero STK push).

## Tech Stack

| Layer       | Choice                                          |
|-------------|------------------------------------------------|
| Backend     | PHP 8.2, Laravel 11 (Blade, no SPA)           |
| Frontend    | Vanilla JS ES6+, plain `<script>` tags         |
| Database    | MySQL InnoDB (InfinityFree shared hosting)     |
| PDF         | barryvdh/laravel-dompdf                        |
| DOCX        | phpoffice/phpword                              |
| SMS OTP     | Africa's Talking                               |
| Payments    | PayHero M-Pesa STK Push                        |
| Notify      | Telegram Bot API                               |
| Hosting     | InfinityFree (FTP deploy via GitHub Actions)   |

## Local Development Setup

### Prerequisites

- PHP 8.2+
- Composer
- MySQL 5.7+ or MariaDB

### Steps

```bash
# 1. Clone the repository
git clone <repo-url>
cd "kenya docs"

# 2. Install dependencies
composer install

# 3. Configure environment
cp .env.example .env
php artisan key:generate

# 4. Edit .env — set DB credentials and third-party API keys

# 5. Run migrations
php artisan migrate --seed

# 6. Serve locally
php artisan serve
```

Then open http://localhost:8000.

## Environment Variables

| Key                    | Description                                         |
|------------------------|-----------------------------------------------------|
| `APP_NAME`             | Application name (default: "Kenya Docs")            |
| `APP_ENV`              | Environment: `local` or `production`                |
| `APP_KEY`              | Laravel encryption key (generated by artisan)       |
| `APP_DEBUG`            | `true` locally, `false` in production               |
| `APP_URL`              | Full URL (e.g. `https://yourdomain.infinityfreeapp.com`) |
| `DB_CONNECTION`        | `mysql`                                             |
| `DB_HOST`              | MySQL host (InfinityFree: provided in cPanel)       |
| `DB_PORT`              | MySQL port (default `3306`)                         |
| `DB_DATABASE`          | Database name                                       |
| `DB_USERNAME`          | Database username                                   |
| `DB_PASSWORD`          | Database password                                   |
| `CACHE_DRIVER`         | `file` (InfinityFree has no Redis)                  |
| `SESSION_DRIVER`       | `file`                                              |
| `QUEUE_CONNECTION`     | `sync` (no queue worker on shared hosting)          |
| `AT_USERNAME`          | Africa's Talking account username                   |
| `AT_API_KEY`           | Africa's Talking API key                            |
| `AT_SENDER_ID`         | SMS sender ID (e.g. `KenyaDocs`)                    |
| `PAYHERO_API_KEY`      | PayHero API key                                     |
| `PAYHERO_CHANNEL_ID`   | PayHero payment channel ID                          |
| `PAYHERO_WEBHOOK_SECRET` | PayHero webhook signature secret                  |
| `TELEGRAM_BOT_TOKEN`   | Telegram bot token                                  |
| `TELEGRAM_CHANNEL_ID`  | Telegram channel/group ID for admin notifications   |

## Deployment

Push to `main` branch — GitHub Actions will install deps, optimize Laravel, and FTP-deploy to InfinityFree automatically.

See [InfinityFree-setup.md](InfinityFree-setup.md) for one-time hosting setup steps.
